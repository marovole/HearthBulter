## ADDED Requirements

### Requirement: Weekly Plan Email Notification

系统 SHALL 在智能时机触发后发送周计划摘要邮件。

#### Scenario: 发送周计划邮件

- **WHEN** 智能时机触发引擎决定推荐周计划
- **THEN** 系统生成周计划摘要
- **AND** 发送邮件到用户注册邮箱
- **AND** 邮件包含「查看详情」和「一键购物」按钮

#### Scenario: 邮件内容结构

- **WHEN** 生成周计划邮件
- **THEN** 邮件包含以下内容：
  - 个性化问候语
  - 本周菜谱概览（7天早中晚餐）
  - 预估总花费
  - 营养摘要（热量、蛋白质等）
  - 「查看详情」按钮（跳转到应用）
  - 「一键购物」按钮（跳转到购物车预览）

#### Scenario: 邮件发送失败重试

- **WHEN** 邮件发送失败
- **THEN** 系统在 1 小时后重试
- **AND** 最多重试 3 次
- **AND** 记录失败原因到日志

#### Scenario: 用户退订邮件

- **WHEN** 用户点击邮件中的「退订」链接
- **THEN** 系统更新用户通知偏好
- **AND** 不再发送周计划邮件
- **AND** 显示退订成功页面
