## ⚙️ 连接类型说明

### Session Pooler (端口 5432)

**用途**: 开发环境、数据库迁移  
**特点**:

- ✅ 支持 DDL 操作（CREATE TABLE、ALTER TABLE 等）
- ✅ 支持事务
- ✅ 支持 PREPARE 语句
- ⚠️ 连接数有限

**何时使用**:

- `pnpm db:push` - 应用 Schema
- `pnpm db:migrate` - 运行迁移
- 数据库维护操作

### Transaction Pooler (端口 6543)

**用途**: 生产环境、高并发查询  
**特点**:

- ✅ 高性能
- ✅ 支持高并发
- ✅ 连接池优化
- ❌ 不支持 DDL 操作
- ❌ 不支持 PREPARE 语句

**何时使用**:

- 生产环境 API 查询
- 高并发读写操作
- Next.js 应用运行时
